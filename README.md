# 🎯 FocusTube

> Distraction-Free YouTube Experience

FocusTube is a Chrome Extension that removes distractions from YouTube so you can stay focused on what actually matters.

---

## 🚀 Features

### 🔹 Normal Mode
- Hide Home Feed
- Hide Shorts
- Hide Comments
- Hide Related / Up Next videos

### 🔹 Advanced Mode
Individually toggle:
- Hide Home
- Hide Shorts
- Hide Comments
- Hide Related videos

### ⌨️ Quick Toggle Shortcut
Ctrl + Shift + F

## 🔧 Installation (Manual)
1. Unzip the archive
2. Go to `chrome://extensions`
3. Enable Developer Mode
4. Click "Load Unpacked"
5. Select the project folder

---

## 🧠 Why FocusTube?

YouTube is designed to:
- Hook you
- Push Shorts
- Recommend endlessly

FocusTube removes the noise so you can:
- Study
- Research
- Watch intentionally
